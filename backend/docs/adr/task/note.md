GET /projects - Projectを一覧取得する (ListProjectsUseCase)
POST /projects - Projectを作成する (CreateProjectUseCase)
GET /projects/:id - Projectを取得する (GetProjectUseCase)
PATCH /projects/:id - Projectの基本情報を更新する (UpdateProjectUseCase)
DELETE /projects/:id - Projectを削除する (DeleteProjectUseCase)
GET /projects/:id/tasks - Project内のTaskを一覧取得する (ListProjectTasksUseCase)
POST /projects/:id/tasks - Project内にTaskを作成する (CreateTaskInProjectUseCase)
POST /projects/:id/tasks:add - 既存TaskをProjectに追加・移動する (AddTaskToProjectUseCase)
POST /projects/:id/tasks:remove - TaskをProjectから外す (RemoveTaskFromProjectUseCase)

GET /tasks - 全Taskを一覧取得する (ListTasksUseCase)
POST /tasks - 単独のTaskを作成する (CreateTaskUseCase)
GET /tasks/:id - Taskを取得する (GetTaskUseCase)
PATCH /tasks/:id - Taskの基本情報を更新する (UpdateTaskUseCase)
DELETE /tasks/:id - Taskを削除する (DeleteTaskUseCase)
POST /tasks/:id:start - Taskを進行中にする (StartTaskUseCase)
POST /tasks/:id:hold - Taskを保留する (HoldTaskUseCase)
POST /tasks/:id:wait - Taskを他者待ちにする (WaitTaskUseCase)
POST /tasks/:id:complete - Taskを完了する (CompleteTaskUseCase)
POST /tasks/:id:reopen - Taskを未着手に戻す (ReopenTaskUseCase)

GET /tasks/:taskId/todo-items - TodoItemを一覧取得する (ListTodoItemsUseCase)
POST /tasks/:taskId/todo-items - TodoItemを作成する (CreateTodoItemUseCase)
PATCH /tasks/:taskId/todo-items/:id - TodoItemの内容を更新する (UpdateTodoItemUseCase)
DELETE /tasks/:taskId/todo-items/:id - TodoItemを削除する (DeleteTodoItemUseCase)
POST /tasks/:taskId/todo-items/:id:complete - TodoItemを完了する (CompleteTodoItemUseCase)
POST /tasks/:taskId/todo-items/:id:reopen - TodoItemの完了を取り消す (ReopenTodoItemUseCase)
POST /tasks/:taskId/todo-items/:id:reorder - TodoItemを並べ替える (ReorderTodoItemUseCase)
PUT /tasks/:taskId/todo-items/:id/frequency - TodoItemの繰り返しを変更・停止する (UpdateTodoItemFrequencyUseCase)

GET /schedules - 個人用Scheduleを一覧取得する (ListSchedulesUseCase)
POST /schedules - 個人Scheduleを作成する (CreateScheduleUseCase)
GET /schedules/:id - Scheduleを取得する (GetScheduleUseCase)
PATCH /schedules/:id - Scheduleの基本情報を更新する (UpdateScheduleUseCase)
DELETE /schedules/:id - Scheduleを削除する (DeleteScheduleUseCase)
POST /schedules/:id:reschedule - Scheduleの日時を変更する (RescheduleScheduleUseCase)
PUT /schedules/:id/frequency - Scheduleの繰り返しを変更・停止する (UpdateScheduleFrequencyUseCase)
GET /schedules/:id/revisions - Scheduleの変更履歴を取得する (ListScheduleRevisionsUseCase)
GET /projects/:id/schedules - ProjectのScheduleを一覧取得する (ListProjectSchedulesUseCase)
POST /projects/:id/schedules - Project内にScheduleを作成する (CreateScheduleUseCase)

GET /tags - 共通Tagカタログを一覧取得する (ListTagsUseCase)
POST /tags - Tagを作成する (CreateTagUseCase)
PATCH /tags/:id - Tagの名前を変更する (RenameTagUseCase)
DELETE /tags/:id - Tagを削除する (DeleteTagUseCase)
POST /tasks/:id/tags:add - TaskにTagを付ける (AddTagToTaskUseCase)
POST /tasks/:id/tags:remove - TaskからTagを外す (RemoveTagFromTaskUseCase)
