# Task2TodayToDo

[English](README.md)

***明日のために生きるな、今日を全力で生きよう。***

task2todaytodo は、タスクとスケジュールを一元管理し、ひとつの構造化された情報源から日々の実行計画を生成するタスク・スケジュール管理システムです。

週単位や月単位でタスクを計画することは、始めるのは簡単でも、維持し続けるのは難しいものです。割り込みによって計画はずれ込み、長期的なカレンダーを手作業で修正し続けることはすぐに大きな負担になります。task2todaytodo は、タスクとスケジュールを構造化された情報源としてまとめて管理し、必要なときに今日の TodoList だけを生成することで、その負担を避けます。

長期的に管理されるタスク・スケジュールと、日々の実行計画を分けて扱うことで、このプロダクトは完璧な長期スケジュールの維持をユーザーに強いることなく、その日に合わせた動的で柔軟な TodoList を作成できます。

# 価値

- タスク管理: プロジェクト、タスク、固定スケジュール、繰り返し作業、単発作業を含むすべてのタスクをひとつの場所で管理します。
- スケジュール管理: 繰り返しまたは単発のタスクに紐づく固定スケジュールを管理します。また、Google Calendar などの外部カレンダーシステムとの同期も行います。
- 今日の TodoList 生成: 管理されているタスクとスケジュールをもとに、その日の実行計画となる TodoList を生成します。

## バックエンドのクイックスタート

前提条件: Docker、Go、Air。

```bash
cd backend
cp .env.example .env # 初回セットアップ時のみ
make env-up
make migrate-up
air
```

API ドキュメント: <http://localhost:8080/swagger/index.html>

便利なバックエンドコマンドの確認:

```bash
make help        # ヘルプを表示
```
